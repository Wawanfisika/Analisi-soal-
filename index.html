Panduan Langkah Demi Langkah Upload ke GitHub Pages

Jadikan aplikasi ini online & bisa diakses siapa saja secara gratis lewat GitHub Pages!

1

Simpan Berkas Aplikasi

Simpan kode HTML ini di komputer Anda dengan nama file index.html.

2

Buat Repositori Baru di GitHub

  1. Buka situs GitHub.com dan masuk ke akun Anda.
  2. Klik tombol hijau New (atau tanda + di kanan atas → New repository).
  3. Beri nama repository, contohnya: analisis-soal.
  4. Pilih opsi Public.
  5. Centang opsi "Add a README file" (opsional). Klik Create repository.
3

Upload Berkas index.html

  1. Di dalam halaman repositori yang baru dibuat, klik tombol Add file → Upload files.
  2. Tarik (*drag and drop*) atau pilih file index.html dari komputer Anda.
  3. Klik tombol hijau Commit changes di bagian bawah.
4

Aktifkan Fitur GitHub Pages

  1. Buka menu Settings di repositori Anda.
  2. Pada menu sebelah kiri, klik Pages.
  3. Pada bagian Build and deployment → Branch, ubah dari None menjadi main (atau master), lalu klik Save.
  4. Tunggu sekitar 1–2 menit. Tautan web online Anda akan muncul di bagian atas (contoh: https://username.github.io/analisis-soal/).
